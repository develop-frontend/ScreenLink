# ScreenLink

ScreenLink — це легкий десктопний застосунок для передачі зображення окремого вікна або екрана з одного ноутбука на інший через локальну мережу.

Проєкт створений насамперед для надійної передачі презентацій з ноутбука, на якому запускається PowerPoint, на другий ноутбук, який використовується для подальшої трансляції або виведення зображення.

## Основна ідея

ScreenLink складається з двох режимів:

- **Sender** — вибирає вікно або екран для трансляції та передає відео.
- **Receiver** — приймає відеопотік і відображає його.

Передача відео здійснюється безпосередньо між комп'ютерами через WebRTC.

WebSocket використовується тільки для службового обміну даними, необхідними для встановлення WebRTC-з'єднання (signaling).

## Основні можливості

- передача окремого вікна або екрана;
- передача презентацій PowerPoint;
- передача відео в реальному часі;
- низька затримка завдяки WebRTC;
- робота через локальну мережу;
- автоматичне встановлення WebRTC-з'єднання;
- автоматичне перепідключення Receiver;
- Sender може запуститися раніше або пізніше за Receiver;
- вибір джерела трансляції через власний інтерфейс застосунку;
- не потребує OBS або NDI;
- працює як окремий Windows-додаток на базі Electron.
